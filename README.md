# ProfessorMon | CBL Project 2IP90

Pokemon Style Battle Simulation (with Professors in TU/e)

## Build instructions
Extract the provided zip file and open a terminal in root directory. The project is set up using maven, so we will compile first, then run it. (Note: `mvn clean` is optional)

```java
mvn compile
mvn exec:java
```

After running the project, a GUI should be visible allowing you to select your professor. This is a 2-player game on the same device.

After selecting your professors, click continue to start the battle. Here you will be able to select moves and see how the battle plays out.
